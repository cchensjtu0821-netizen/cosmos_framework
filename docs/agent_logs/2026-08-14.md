## `INVESTIGATING` Classify NPUCL unsupported ONNX patterns

- New OMC evidence reports unsupported internal `BroadcastTo`, `Sin`, `Cos`,
  `SpaceToDepth`, and `DepthToSpace` operations. Added a read-only analyzer
  that inspects the final ONNX without loading external tensor data and emits
  per-node producer, consumer, and static-shape context plus JSON counts.
- The analyzer classifies an `Expand` as removable only when every consumer's
  binary ONNX broadcast can reproduce the same static result, and separately
  identifies equal-rank single-axis `1 -> N` expansions that one `Concat` can
  reproduce. Backend support for the resulting implicit broadcast is still a
  separate OMG/OMC requirement.
- `Sin` and `Cos` are never classified as safe deletions: equal input/output
  shapes do not preserve RoPE values. Constant-only dependency chains are
  reported as possible constant-fold candidates instead.
- Static rank-4 `SpaceToDepth` and `DepthToSpace` are checked for exact lowering
  eligibility to fixed one-hot `Conv` and mode-aware `ConvTranspose`, including
  block-size divisibility, expected shapes, and proposed weight sizes.
- Server analysis of the 4,311-node quantized compatible model found 118
  `Expand` nodes: two can be bypassed through a proven binary `Add` broadcast,
  112 can become two-input `Concat(axis=2)`, and four constant-fill expansions
  can be materialized as initializers. Both spatial rearrangements are eligible
  for exact one-hot convolution lowering. Of six trigonometric nodes, only the
  two constant RoPE nodes can be folded; four timestep-dependent nodes must
  remain and must not be deleted.
- Added an independent postprocessor that implements those exact lowerings,
  prunes newly unreachable shape scaffolding, runs `onnx.checker`, and reports
  all remaining target nodes. It deliberately leaves the four dynamic
  timestep `Sin`/`Cos` nodes unresolved rather than changing model semantics.
- Affected files: `onnxsrc/analyze_omg_unsupported_patterns.py`,
  `onnxsrc/rewrite_omg_unsupported_patterns.py`, and focused tests. Validation:
  Python compilation and 13 pure structural/channel-order unit tests pass. The
  local workspace lacks NumPy, ONNX, and ONNX Runtime, so actual graph rewrite,
  checker, and numerical equivalence remain server-side requirements.
- Server post-rewrite audit confirms `Expand=0`, `SpaceToDepth=0`, and
  `DepthToSpace=0`; exactly four runtime-dependent timestep `Sin`/`Cos` nodes
  remain, with zero constant-fold or safe-delete candidates. This is the
  expected structural result and confirms all enabled exact lowerings applied.
- Next action: compare both model outputs against the input model and confirm
  OMC accepts the implicit `Add` broadcasts and one-hot Conv/ConvTranspose. To
  reach a zero target-node count without approximation, move the two complete
  timestep sinusoidal embeddings across the ONNX boundary and compute them in
  the host, or compile separate constant-timestep graphs; this interface choice
  must be made before rewriting the four dynamic trigonometric nodes.
- For structural power/performance evaluation where numerical equivalence is
  explicitly not required, added a default-off profiling switch that bypasses
  each dynamic `Sin`/`Cos` output with its same-shaped input. The switch keeps
  the existing model inputs and tensor ranks but marks the JSON report as
  profiling-only and non-equivalent; it must not be used for accuracy results.
