## `INVESTIGATING` Classify NPUCL unsupported ONNX patterns

- New OMC evidence reports unsupported internal `BroadcastTo`, `Sin`, `Cos`,
  `SpaceToDepth`, and `DepthToSpace` operations. Added a read-only analyzer
  that inspects the final ONNX without loading external tensor data and emits
  per-node producer, consumer, and static-shape context plus JSON counts.
- The analyzer classifies an `Expand` as removable only when every consumer's
  binary ONNX broadcast can reproduce the same static result, and separately
  identifies equal-rank single-axis `1 -> N` expansions that one `Concat` can
  reproduce. Backend support for the resulting implicit broadcast is still a
  separate OMG/OMC requirement.
- `Sin` and `Cos` are never classified as safe deletions: equal input/output
  shapes do not preserve RoPE values. Constant-only dependency chains are
  reported as possible constant-fold candidates instead.
- Static rank-4 `SpaceToDepth` and `DepthToSpace` are checked for exact lowering
  eligibility to fixed one-hot `Conv` and mode-aware `ConvTranspose`, including
  block-size divisibility, expected shapes, and proposed weight sizes. No graph
  rewrite has been implemented yet.
- Affected files: `onnxsrc/analyze_omg_unsupported_patterns.py` and its focused
  test. Validation: nine pure structural unit tests, Python compilation, and
  whitespace checks passed; Ruff and local ONNX runtime are unavailable.
